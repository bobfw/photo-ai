# Seedream 提示词指南（摘要）

来源：火山方舟《Seedream 4.0-5.0 提示词指南》，索引见 https://ark.volcengine.com/llms.txt
（文档页地址后加 `.md` 可得 Markdown 版）。适用于本仓库所有文生图 / 图生图提示词，
改提示词前先过一遍本页。5.0 lite / 4.5 / 4.0 理解力强，**简洁准确优于堆砌华丽词汇**。

## 通用规则

1. 用自然语言写清 **主体 + 行为 + 环境**；有美学要求时补充 风格、色彩、光影、构图。
   - 好：一个穿着华丽服装的女孩，撑着遮阳伞走在林荫道上，莫奈油画风格。
   - 差：一个女孩，撑伞，林荫街道，油画般的细腻笔触。
2. 有明确用途时写明图像类型（logo、海报、UI 界面、分镜……）。
3. 风格需求用精准风格词或参考图。
4. 要渲染的文字放 **双引号** 中：标题为 "Doubao Seedream 4.5"。
5. 编辑指令指明对象，不用模糊代词；要保留的部分显式写「保持……不变」。

## 任务要点

- **文生图**：细节多就逐项描述精准控制；知识类内容（公式、图表）用专业术语，写清可视化形式、版式、风格。
- **图像编辑**（增 / 删 / 替换 / 修改）：指明对象和变化，如「去掉女生的帽子」「把最大的面包人换成牛角包形象，保持动作和表情不变」。
- **难定位时**：在图上用箭头、线框、涂鸦标出区域，提示词里说「红色涂抹位置放入电视」。
- **参考图生图**：两段式——①指明要保留的参考元素（人物形象 / 风格 / 款式）②描述生成画面。
- **草图 → 高保真**：提供清晰原图；写「遵循图中文字内容进行生成」；点明须与原图一致的关键项（布局、家具位置）。
- **多图输入**：用编号指代——「将图一的主体替换为图二的主体」「参考图三的风格」。
- **多图输出**：用「一系列 / 一套 / 组图」或具体数字（「生成四张图，影视分镜……」）触发，风格统一、角色连贯。
